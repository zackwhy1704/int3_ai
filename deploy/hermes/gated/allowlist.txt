# Company Brain — default-deny route allowlist for the Hermes backend.
#
# Format: METHOD /path   or   METHOD /prefix*        (query strings ignored)
# Anything not listed gets 403 at the proxy and never reaches the backend.
#
# Derived by measurement, not by reading the source: every rule below was
# observed in a real desktop session against stock Hermes (boot, chat, sessions,
# artifacts, scheduled jobs, files pane, review pane), then the app was re-run
# with only these rules to see what broke. See TASK H in the spike report.
#
# RE-MEASURED for Hermes v0.22.6 (launcher M0, 2026-11-03): stock v0.22.6 desktop (dev build)
# against a v0.22.6 backend with route_proxy in MEASURE mode: boot, chat send over /api/ws,
# session reopen, Artifacts, Scheduled jobs, Capabilities, Messaging, files pane, settings.
# 33 distinct routes seen, 13 not on the v0.21.7 list; 9 admitted below (marked v0.22.6),
# 5 excluded at the bottom (messaging/platforms is now a stub, see the end). Handlers cited at v0.22.6 (hermes_cli/web_routers/*). NOT
# exercised (model key rejected during the run): tool-call turns, assistant output, artifacts
# produced by answers.
#
# NOTE on /api/ws: it is ONE route but it is the gateway's JSON-RPC channel.
# Admitting it admits every method behind it, including shell.exec. A path
# allowlist cannot constrain what travels inside the socket.

# --- app shell / boot ----------------------------------------------------
GET  /api/status                    # boot readiness + version
GET  /api/health                    # connection health poll
GET  /api/config                    # composer + UI settings
GET  /api/config/defaults           # settings defaults merged at boot
GET  /api/profiles                  # profile list (single profile in practice)
GET  /api/profiles/active           # which profile the window is on
GET  /api/audio/voice-live/status   # v0.22.6 boot poll; read-only status (audio.py:180)
GET  /api/tools/terminal/backends   # v0.22.6 boot; read-only list (tools.py:645). Choosing one is a
                                    # config write (PUT /api/config), which stays excluded.

# --- chat ----------------------------------------------------------------
GET  /api/ws                        # gateway WebSocket: prompts, streaming replies, tool events
GET  /api/model/info                # composer shows the active model
GET  /api/model/options             # v0.22.6 model picker list; read-only (models.py:138)
GET  /api/model/auxiliary           # v0.22.6 settings: auxiliary models; read-only (models.py:219)
GET  /api/model/moa                 # v0.22.6 settings: mixture-of-agents; GET only (models.py:272;
                                    # PUT models.py:303 excluded)
GET  /api/config/schema             # v0.22.6 settings form schema; read-only (config_env.py:100)
GET  /api/tools/toolsets            # v0.22.6 capabilities: toolset list; read-only (tools.py:223)
GET  /api/skills                    # v0.22.6 capabilities: installed skills; GET only (skills.py:343;
                                    # POST skills.py:457 = install, excluded)
GET  /api/sessions/*                # transcript load: /{id}/messages, /{id}/timeline
POST /api/sessions/owner-backfill   # boot-time ownership repair for the session list

# --- sessions ------------------------------------------------------------
GET  /api/profiles/sessions         # session list
GET  /api/profiles/sessions/sidebar # sidebar session list

# --- artifacts -----------------------------------------------------------
# Artifacts are extracted from session messages: covered by GET /api/sessions/*.

# --- files pane (read only) -----------------------------------------------
GET  /api/fs/default-cwd            # pane's starting directory
GET  /api/fs/list                   # directory listing (confined by HERMES_DASHBOARD_FILES_ROOT)
GET  /api/fs/read-text              # text preview
GET  /api/fs/read-data-url          # image/PDF preview
GET  /api/fs/git-root               # v0.22.6 pane boot: nearest .git ancestor of the pane's folder, or
                                    # null (files.py:1383-1397). Read-only, but NOT behind
                                    # _hosted_fs_read_guard: it can name a .git ancestor of ANY path. In
                                    # the gated image the only ones outside /opt/data are uv-cache
                                    # sentinels (/opt/hermes/uv-cache/sdists-v10, /root/.hermes/cache/
                                    # uv/sdists-v10); no file content is returned. Without it the
                                    # pane shows "Unreadable" (measured 2026-11-04, workspace cwd).
# EXCLUDED: POST /api/fs/write-text — unconfined write (no Request, no guard,
#           no sensitive-path denylist). Not needed: users ask, they do not edit.

# --- review pane (read only) ----------------------------------------------
GET  /api/git/status                # branch + change counts
GET  /api/git/review/list           # changed files
GET  /api/git/review/diff           # per-file diff
GET  /api/git/review/ship-info      # ahead/behind summary
GET  /api/git/review/rev-parse      # ref resolution
GET  /api/git/file-diff             # file diff view
# EXCLUDED: git stage / commit / push / worktree mutations.

# --- scheduled jobs (read only) -------------------------------------------
GET  /api/cron/jobs                 # job list
GET  /api/cron/blueprints           # job templates shown on the Cron page
# EXCLUDED: POST /api/cron/* (create/trigger jobs) — a scheduled agent run is
#           code execution on a timer; provisioned by us, not created by users.

# --- MCP tool calls ---------------------------------------------------------
# None at this layer: the agent calls MCP tools from inside the backend process.
POST /api/mcp/servers/brain/test    # v0.22.6 boot: connect to OUR provisioned brain server, list its
                                    # tools, disconnect; no config write (mcp.py:204-240). Exact path:
                                    # no other server name is testable.
# EXCLUDED: /api/mcp/servers (add/edit/delete), /api/mcp/catalog/install — the
#           brain MCP server is provisioned container-side; users do not add tools.

# --- seen in the v0.22.6 measurement and deliberately EXCLUDED -----------------
# GET /api/hermes/update/check   (actions.py:289) update surface; the backend is pinned by us
#                                (build-base.sh) and never updated from the desktop.
# GET /api/pairing               (ops.py:84) pairing is not part of the pilot. The Messaging page
#                                swallows this failure by design (apps/desktop/src/app/messaging/
#                                index.tsx:239-253), so it stays a plain 403.
# GET /api/audio/elevenlabs/voices (audio.py:220) external TTS provider listing (egress-locked).
# GET /api/skills/hub/official   (skills.py:123) installable-skills catalog; installs are not
#                                offered to users.

# --- stubs: answered by the proxy itself, never forwarded (route_proxy.py) --------
# GET /api/messaging/platforms (messaging.py:938) is NOT reached: the real handler returns the
# backend's env path and per-platform credential state, and messaging bots are not offered. A 403
# here made the Messaging page spin forever with a "failed to load" toast (index.tsx:213-223,572);
# an empty catalog renders the page's own empty list. PUT/test on a platform stay denied (no rows
# to act on anyway).
GET /api/messaging/platforms => {"platforms": []}
